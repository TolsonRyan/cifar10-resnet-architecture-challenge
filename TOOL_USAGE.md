# Tool and source disclosure

Codex assisted with local data validation, environment setup, original project code,
debugging, GPU experiment execution, artifact checks, figures, and draft documentation.
All numerical results in the report are derived from saved, completed local runs.
No pretrained weights, external training images, or hidden-label sources were used.

The user remains responsible for understanding and reviewing the implementation and
the final course submission. Team identities, course registration, Kaggle submission,
and public repository sharing have not been asserted or performed on the user's behalf.
The user created a private GitHub repository; Codex assisted with synchronizing the
prepared code, configurations, experiment records, and report sources to that repository.

The mathematical ideas are cited in README and the report bibliography. PyTorch,
NumPy, Pillow, Matplotlib, and other installed dependencies retain their own licenses.
No blanket license for the competition code is assigned here before the user chooses
an appropriate sharing policy and checks the course/Kaggle requirements.

Local source snapshots in `runs/*/source/` preserve the scripts present at each run's
start. Subsequent reporting and audit improvements do not change the trained models.
